# Paper Calendar 设计案

## 目标
基于原桌面便签框架，展示多个会议的摘要截止、正文截止、审稿发布、回复截止、最终结果五个日期。精度为本地日期，另有论文 / 备注。正文、审稿意见全文的独立编辑与多轮审稿尚未纳入。

## 视觉与布局
默认窗口 560 × 240，最小 450 × 180。无边框工具窗口，隐藏任务栏与 Alt+Tab 项；顶部依次为标题、Lock、新建、退出。没有标语、区间长度、导航箭头、详情区。图例与会议数量合并在底栏，不另占一行。

会议名称列固定 124px，每行 40px，共享横轴，列表支持纵向滚动。名称过长时省略，悬停可查看全名，单击打开编辑框。

**节点是主信息**。五个节点使用不同颜色和准确日期坐标，图例对应节点类型：

| 节点 | 默认颜色 |
| --- | --- |
| 摘要截止 | 青绿 #538E88 |
| 正文截止 | 蓝 #6085B8 |
| 审稿发布 | 赭黄 #C69C55 |
| 回复截止 | 梅灰 #A47796 |
| 最终结果 | 草绿 #72925B |

摘要之前没有区间。仅在相邻节点间绘制满行高的淡色背景，区间含义为“摘要截止至正文截止 / 等待审稿 / 意见回复 / 等待结果”。区间使用终点类型对应颜色的浅色，仅用于辅助，不作为另一套图例。同日节点不人为扩宽区间。

日期标签仅显示 MM/dd，浅色底、同色边框、加粗深色文字；文字保留色相并加深，使其与浅色底的对比度达到 7:1。悬停节点或日期标签可查看事件名称、完整日期及距离本地今天的天数：还有 N 天 / 今天 / 已过 N 天。点击节点或日期标签展开详情卡片，包含会议名称、节点类型、完整日期及剩余天数；点击外部或按 Esc 收起，不改变行高。

标签按实际字体宽度计算，枚举两行排布并选择位移最小的方案；密集时允许横向偏移，用引线连接原始节点，节点本身不移动。标签始终限制在时间轴左右边界内；缩放、调整宽度及跨屏字体缩放后重新计算。顶部刻度按可用像素间距减少。

今日线为 #D66147，每分钟刷新；在当前视野内绘制竖线；超出视野时在对应一侧显示“← 今天 MM/dd”或“今天 MM/dd →”，点击可回到今天。

## 交互
- 滚轮：上滚移向过去，下滚移向未来，每步约可见范围的 1/20。
- Ctrl + 滚轮：缩放，范围 14–730 天，保持视野中心日期。
- Shift + 滚轮或滚动条：上下滚动会议列表。
- 点击越界提示：将今天定位到横轴约 1/4 处。顶部不再保留今天按钮；启动时采用相同定位，保留上次缩放天数，不恢复上次平移位置。
- 五项日期均可留空，新建时不猜测默认日期；旧记录保留四个原始日期，最终结果为空，不推测新日期。
- 点击名称：编辑名称、五个日期、论文 / 备注；日期框支持直接输入或粘贴 YYYY-MM-DD、YYYY/MM/DD、YYYYMMDD；旁边的日历打开时参考当前值或前一已填日期。名称必填，已填写日期满足摘要 ≤ 正文 ≤ 审稿 ≤ 回复 ≤ 最终结果。取消保留原记录。
- 删除：在编辑框内操作，二次确认。
- 会议排序：拖动名称左侧六点拖柄上下排序；聚焦列表并选择行后，也可 Alt + ↑ / ↓ 调整。排序立即保存，失败回滚。
- 图例选色：点击图例打开颜色选择器，节点、标签、区间联动更新，颜色保存到 settings.ini。
- Unlock：拖动顶部标题区域移动窗口，拖动边缘缩放。
- Lock 使用闭锁图标，Unlock 使用开锁图标，悬停显示状态和操作说明。
- Lock：禁止窗口移动和边缘缩放；编辑、排序、时间导航仍可使用，状态持久化。

Windows 边缘命中测试使用 GetWindowRect 的物理坐标和按 DPI 缩放的边缘宽度，避免将物理屏幕坐标与 Qt 逻辑坐标混算。标题拖动交给 QWindow::startSystemMove。

## 数据
Qt AppDataLocation 下保存 conferences.json 和 settings.ini，可通过 --data-dir 指定位置。JSON 版本为 2（兼容读取版本 1），每项包含 UUID、name、note、五个 ISO 日期值（任意日期可为 null）；数组顺序即显示顺序。旧便签数据不改写。

QSaveFile 原子替换，提交成功后才显示已保存。加载时校验版本、数组、名称、日期有效性与顺序；损坏文件禁止覆盖。编辑、删除、排序写入失败时回滚内存。窗口位置、大小、Lock、可见日期、缩放范围及五类颜色由 QSettings 持久化。

当前不支持多个实例并发编辑、云同步、撤销历史、具体截止时刻或 AoE 换算。HTML 是独立设计示意，会议和颜色修改仅存在当前页面内；Qt 保存真实数据和偏好。

## 桌面层级
DesktopController 固定桌面伴随，不提供其他模式。前台切换至 Progman / WorkerW / SHELLDLL_DefView 时，在下一个事件循环立即检查原生可见性、最小化状态，以及窗口上方是否存在相交的可见桌面宿主。已经显示在桌面前方时不操作；确需恢复才临时置顶 50ms，再恢复普通层级。180ms 后进行一次条件复核，用于覆盖 Win+D 动画，不无条件二次提升。只有隐藏或最小化时调用 ShowWindow；仅撤销本控制器自己设置的临时置顶。旧 settings.ini 的模式设置不再读取。

窗口使用与最初便签框架相同的半透明灰色 RGBA(48,48,48,128)。根窗口开启 WA_TranslucentBackground，内部容器透明，避免叠加多层灰色。文字和控件采用浅色；编辑和颜色对话框保持不透明以保证输入清晰。

实时读取当前 winId，SetWindowPos 使用 SWP_NOACTIVATE。切到其他应用时取消延迟并撤销临时置顶；切换模式取消计时器；析构卸载钩子。未依赖缓存 Explorer 句柄或 WorkerW 重父化。

Win+D / Win+M、多屏、Explorer 重启、全屏应用、虚拟桌面及休眠恢复仍需要目标 Windows 桌面验收；自动测试不能替代这些系统行为检查。

## 实现与验证
CalendarWindow 负责页面、编辑与持久化；Timeline 负责节点、区间、标签避让、工具提示、拖放及滚轮；DesktopController 隔离原生层级逻辑。旧 StickyNote / ToolBar 保留作为参考，不参与构建；原 Monitor.cpp 已有改动保留。

使用 Qt Widgets 和 C++17。自动检查覆盖日期校验、保存重载、损坏文件保护、滚轮平移和缩放中心、密集标签及边界、排序与 Lock 恢复、图例颜色保存、锁定时编辑、文字对比度、摘要前无区间。另提供 Windows 原生边缘命中测试及渲染快照。
